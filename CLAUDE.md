# Horizon — Jina AI 301 SKO Demo

## Project Overview
Travel hotel search demo app showcasing 5 Jina AI models integrated with Elastic for SKO FY27 enablement.

**Event**: May 13 2026, Venetian Las Vegas, ~296 Field Engineers
**Format**: 17-min slides → 33-min live demo (6 stations) → 5-min Q&A

## Key Commands
```bash
make dev        # Start Next.js dev server (ui/)
make index      # Run hotel indexing pipeline
make fallbacks  # Capture fallback responses for offline mode
make images     # Generate hotel images via nano-banana
```

## Architecture
- **Framework**: Next.js 14 + TypeScript + Tailwind in `ui/`
- **Theme**: Elastic on-brand (dark navy, Elastic Blue, Teal, Pink accents)
- **Data**: ~150 synthetic hotels in `data/hotels.json`
- **Images**: Local PNGs in `ui/public/images/hotels/` (generated by nano-banana)
- **ES Index**: `horizon-hotels` with semantic_text, geo_point, dense_vector (CLIP)

## Jina Models Used
| Station | Model | API |
|---|---|---|
| Ingest | Reader | `r.jina.ai` (direct) |
| Find | Embeddings v5 | EIS: `.jina-embeddings-v5-text-small` |
| Rank | Reranker v3 | EIS: `.jina-reranker-v3` |
| Look | CLIP v2 | `api.jina.ai/v1/embeddings` (direct) |
| Describe | VLM | `api-beta-vlm.jina.ai` (direct) |

## Environment Variables
See `.env.example`. Copy to `ui/.env.local` before running.

## Fallback Mode
Toggle in the app header. Loads pre-recorded responses from `data/fallbacks/`.
Run `make fallbacks` to capture fresh responses before the event.
